# LLM 벤치마커

구독으로 쓰는 Claude와 Grok 모델에 같은 과제, 같은 채점 규칙을 적용해 작업별 기준표를 만드는 개인용 웹 서비스입니다. 인터넷 속도 측정처럼 시작 버튼을 누르면 분류별 점수와 종합 점수가 나옵니다.

## 켜는 방법

`벤치마커 시작.command` 파일을 두 번 누릅니다. 터미널 창이 열리고 브라우저에 `http://127.0.0.1:4173` 이 열립니다. 터미널 창을 닫으면 서비스가 꺼집니다.

## 동작 방식

- 이 Mac에 설치된 `claude`, `grok` 명령줄 도구를 직접 호출합니다. 두 도구의 구독 로그인을 그대로 쓰므로 API 키가 필요 없습니다.
- 그래서 이 서비스는 이 Mac 안에서만 동작합니다(주소 `127.0.0.1`). 인터넷에 올리면 구독 계정이 외부에 노출되므로 클라우드 배포를 하지 않습니다.
- 측정 환경은 두 가지입니다.
  - 실사용 환경(기본): 사용자의 지침, 스킬, 도구가 모두 붙은 상태. 모델의 파일 쓰기는 측정용 임시 폴더로 제한합니다.
  - 순수 모델: 지침과 도구를 뺀 모델 자체.
- 결과는 `data/runs/` 에 측정 한 번당 파일 하나로 저장됩니다.

## 측정 분류 (9개, 과제 33개)

코딩, 디버깅, 리서치(자료 분석), 플래닝, 반복업무 정확도, 추론과 계산, 기획, 창의력, 이미지 제작(SVG 코드).

- 정답이 있는 분류는 숨은 테스트나 규칙으로 채점합니다.
- 기획과 창의력은 형식 규칙 검사에 더해, Claude 모델 하나와 Grok 모델 하나가 작성자를 모르는 상태로 채점합니다.
- 한계는 서비스 화면의 「측정 방법」 탭에 적혀 있습니다.

## 측정 변수

- 모델: `config.json` 의 목록에서 고릅니다. 설치된 `claude` 가 아직 모르는 새 모델은 `behavesAs` 에 기존 모델 이름을 적어 등록합니다.
- 추론 강도: 기본값, low, medium, high, xhigh. 여러 개를 고르면 모델 × 강도 조합마다 따로 측정합니다.
- 측정 깊이: 빠른 측정(분류당 가장 어려운 과제 1개, 총 9개)과 정밀 측정(전체 33개).
- 측정 환경: 실사용 환경과 순수 모델.

## 알려진 한계: 정확도 점수가 만점에 몰립니다

2026-11-10 시범 측정에서 가장 가벼운 두 모델(Claude Haiku 5.5, Grok 4.5)이 추론 강도 low에서도 정답 분류 7개 대부분에서 만점을 받았습니다. 요구 사항이 명확하고 한 번의 요청으로 끝나는 과제에서는 모델 간 정확도 차이가 드러나지 않았습니다. 이 조건에서 실제로 갈린 것은 응답 시간, 입력 토큰량, 정가 기준 비용입니다. 상위 모델 간의 정확도 차이를 보려면 여러 단계에 걸친 긴 작업 과제가 더 필요합니다.

## 설정

`config.json` 에서 모델 목록, 심사 모델, 과제당 제한 시간, 동시에 측정할 모델 수를 바꿉니다. 새 모델이 나오면 `models` 에 한 줄을 추가합니다.

## 검증

```bash
npm test
```

채점기 자체를 검증합니다. 기준 답안이 만점을 받는지, 무의미한 답이 저점을 받는지, 디버깅 과제의 버그 원본이 탈락하는지, 모델이 쓴 코드를 실행하는 격리 프로세스가 파일 쓰기와 무한 반복을 막는지 확인합니다.

## 안전 장치

- 서버는 `127.0.0.1` 에만 열리고, 다른 이름이나 다른 사이트에서 온 요청은 거부합니다.
- 화면에서 고를 수 있는 모델은 `config.json` 에 적힌 것뿐이며, 명령은 셸을 거치지 않고 인자 배열로 실행합니다.
- 모델이 쓴 코드는 파일 쓰기, 다른 프로그램 실행, 환경 변수 접근, 네트워크 접속이 막힌 별도 Node 프로세스에서 5초 제한으로 실행합니다. 그 프로세스에는 입력값만 전달하고 정답은 전달하지 않으며, 정답 비교는 바깥에서 합니다. 실행 결과는 실행할 때마다 새로 만드는 일회용 표식이 붙은 줄만 인정합니다. 네트워크를 차단할 수단이 없는 환경에서는 모델이 쓴 코드를 실행하지 않습니다.
