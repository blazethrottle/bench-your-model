무엇을 어떻게 재는가

모든 모델에 같은 과제, 같은 문장, 같은 채점 규칙을 적용합니다. 각 구독의 명령줄 도구(claude, grok)를 이 컴퓨터에서 직접 호출하므로 API 키가 필요 없고, 구독으로 실제 쓰는 환경 그대로 측정합니다.

점수 계산

과제 점수는 0~100점입니다. 분류 점수는 그 분류 과제들의 평균이고, 종합 점수는 분류 점수의 단순 평균입니다. 속도와 비용은 종합 점수에 넣지 않고 따로 표시합니다.

정답이 없는 과제(기획, 창의력)

형식과 제약은 규칙으로 검사하고, 품질은 Claude 모델 하나와 Grok 모델 하나가 작성자를 모르는 상태로 채점한 값의 평균을 씁니다. 두 진영의 심사자를 함께 쓰는 이유는 한쪽 심사자가 자기 진영의 글을 선호할 가능성을 상쇄하기 위해서입니다.

이 측정의 한계

  • 정답이 있는 과제는 가장 가벼운 모델도 대부분 만점을 받습니다. 빠른 측정과 정밀 측정에서는 점수보다 응답 시간, 입력량, 비용의 차이를 보세요. 모델 간 품질 차이는 고난도 측정, 그중에서도 정답이 없는 최적화 과제에서 드러납니다.
  • 고난도 측정은 과제당 최대 20분이 걸리고 사용량을 많이 씁니다. 제한 시간을 넘기면 그때까지 작업 폴더에 남긴 결과로 채점하며, 글로 답하는 과제는 0점이 됩니다.
  • 과제 수가 적습니다(빠른 측정은 분류당 1개, 정밀 측정은 2~3개). 점수 차이가 10점 안쪽이면 우열로 읽지 마세요. 같은 측정을 다시 하면 점수가 달라질 수 있습니다.
  • 실사용 환경 점수는 지침, 스킬, 도구 설정을 바꾸면 달라집니다. 그래서 측정마다 당시 환경의 기본 입력 토큰 수를 함께 기록합니다.
  • 웹 검색으로 최신 정보를 찾는 능력은 재지 않습니다. 검색 결과가 시점마다 달라 같은 기준을 적용할 수 없기 때문입니다. 리서치 분류는 주어진 자료를 분석하는 능력만 잽니다.
  • 이미지와 영상을 직접 만드는 능력은 재지 않습니다. 이 서비스가 호출하는 모델은 글과 코드를 출력합니다. 이미지 분류는 그림을 코드(SVG)로 그리는 능력만 재는 실험 항목입니다.
  • 과제는 이 서비스를 만든 Claude가 작성했습니다. Claude 계열에 유리하게 치우쳤을 가능성이 있습니다. 채점은 대부분 규칙과 숨은 테스트로 하므로 심사 편향의 영향은 기획과 창의력 분류에 한정됩니다.
  • 비용은 각 도구가 보고하는 정가 기준 추정값이며 구독 요금과는 다릅니다.
  • 추론 강도 "기본값"은 강도를 지정하지 않고 호출한 결과입니다. 실사용 환경에서는 내 설정 파일에 모델별로 적어 둔 강도가 적용됩니다. 모델이 지원하지 않는 강도를 고르면 그 조합은 오류로 중단되고 점수에 넣지 않습니다.
  • Grok Bot 앱은 요청마다 모델을 자동으로 고릅니다. 이 서비스는 모델을 지정할 수 있는 grok 명령줄 도구로 측정하므로, 앱에서의 체감과 다를 수 있습니다.
